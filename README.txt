DienstBuddy – Installierbare Version

Wichtig:
Eine PWA kann nicht zuverlässig direkt aus einer lokalen Datei (file://) installiert werden.
Sie muss über HTTPS oder über localhost geöffnet werden.

Einfachste kostenlose Möglichkeiten:
1. Ordner bei GitHub Pages, Netlify oder Cloudflare Pages hochladen.
2. Danach die Webadresse auf dem Handy öffnen.
3. Android/Chrome: Menü → App installieren / Zum Startbildschirm.
4. iPhone/Safari: Teilen → Zum Home-Bildschirm.

Die Schichtdaten und der Stundenlohn werden lokal im Browser gespeichert.
Die Foto-Texterkennung lädt Tesseract.js aus dem Internet und benötigt dafür eine Verbindung.
