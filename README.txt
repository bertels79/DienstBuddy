Schichtiva V4.1 – Frei wählbare Dienstplanfarben

Schichtiva V4.1 erweitert den Dienstplan um eine individuell anpassbare Farbdarstellung.

Neu in V4.1:
- Jede gespeicherte Schicht kann eine eigene, vom Nutzer wählbare Farbe bekommen.
- Die Farben für Frei, Urlaub und Krank können unter „Einstellungen“ selbst gewählt werden.
- Auch individuelle Einträge können mit einer eigenen Farbe dargestellt werden.
- Die Farben werden lokal auf dem jeweiligen Gerät gespeichert.
- Bestehende Kalendereinträge bleiben erhalten.
- Bereits vorhandene Schichten erhalten zunächst Standardfarben und können anschließend individuell angepasst werden.

So lassen sich unterschiedliche Schichten, freie Tage, Urlaub und Krankheit im Kalender schneller erkennen und besser auseinanderhalten.

Weiterhin enthalten sind alle Funktionen aus Schichtiva V4, darunter Terminbereich, Telefonliste, Erste-Hilfe-Kompass, Dienstplan-Scan, Auswertungen, Zuschlagsberechnung und weitere Smartphone-Optimierungen.

Schichtiva wird Schritt für Schritt weiterentwickelt, getestet und verbessert.
