Schichtiva V3.7.3 – ausgebauter Teststand

Der Erste-Hilfe-Kompass wurde innerhalb V3.7.3 weiter ausgebaut:
- großer lokaler Wortschatz mit Synonymen für Körperregionen, Schmerzen, Blutungen,
  neurologische Beschwerden, Atemwege, Magen-Darm, Verletzungen, Haut,
  Allergien, Vergiftungen, Verbrennungen, Verätzungen, Hitze/Kälte u.v.m.
- Mehrwort-Eingaben werden normalisiert und kombiniert.
- Unbekannte Begriffe enden nicht mehr in einer Sackgasse, sondern können
  einen allgemeinen Sicherheits-/Dringlichkeitscheck starten.
- Vor jedem Fachpfad läuft ein einheitlicher Sicherheitscheck auf zentrale
  112-Warnzeichen.
- Danach folgt der passende Fragepfad, immer eine Frage gleichzeitig.
- Ergebnis: 112 / dringende medizinische Abklärung bzw. 116117 /
  keine akuten Warnzeichen / Giftnotruf.
- Link zum offiziellen 116117 Patienten-Navi als zusätzliche professionelle
  Ersteinschätzung.
- Keine Diagnose.

WICHTIGE GRENZE:
Eine wirklich vollständige medizinische Wissens- und Triage-Datenbank wie SmED
kann nicht seriös als selbst erstellte lokale Datenbank ausgegeben werden.
SmED ist ein Medizinprodukt Klasse IIb. Dieser Kompass bleibt deshalb bewusst
ein Erste-Hilfe-/Warnzeichen-Kompass und verweist für die professionelle
strukturierte Ersteinschätzung zusätzlich auf das offizielle Patienten-Navi.

Grundlagen: gesund.bund.de Notruf/Notaufnahme; KBV/116117 zu SmED;
BfR Giftinformationszentren, Stand 22.07.2026.


NEU – Reanimation/AED:
Wenn keine normale Atmung bestätigt wird:
1. 112 + sofort Herzdruckmassage.
2. Frage: Ist ein AED verfügbar?
3. JA -> geführte AED-Anwendung + HLW weiterführen.
4. NEIN -> geführte HLW: Mitte Brustkorb, 100–120/min, 5–6 cm,
   vollständige Entlastung; geschulte Helfer 30:2, ungeschulte Helfer
   kontinuierliche Herzdruckmassage.
5. Im HLW-Pfad kann jederzeit auf „AED ist jetzt da“ gewechselt werden.

Grundlage: GRC/ERC Reanimationsleitlinien 2025.
